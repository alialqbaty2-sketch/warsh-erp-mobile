# Warsh ERP Mobile (MVP)

هذه نسخة أولية لتطبيق Warsh ERP موجهة للمشرفين في الميدان.

الميزات الحالية في هذه النسخة:
- تسجيل دخول بسيط (اسم المستخدم فقط)
- قائمة المهام المحفوظة محلياً
- فتح مهمة، تسجيل تقدم، وإرفاق صورة
- تخزين محلي باستخدام SQLite
- طابور مزامنة بسيط (علمية - تمييز سجل كمزامن)

متطلبات:
- Flutter SDK مثبت
- Android SDK (لإنشاء APK)

طريقة التشغيل محلياً:
1. استنساخ المستودع:
   git clone https://github.com/alialqbaty2-sketch/warsh-erp-mobile.git
2. الانتقال إلى المجلد:
   cd warsh-erp-mobile
3. تثبيت الحزم:
   flutter pub get
4. تشغيل التطبيق على جهاز متصل أو محاكي:
   flutter run

لبناء ملف APK:
   flutter build apk --release
